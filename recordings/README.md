# Recordings Directory

This directory contains meeting recordings and their analysis results.

## Directory Structure

- `uploads/` - Place meeting MP4 files here for analysis
- `processed/` - Processed audio/video files ready for analysis
- `analyzed/` - Analysis results from Hume AI

## Usage

1. Upload your meeting MP4 files to the `uploads/` directory
2. The Circle AI agent will automatically detect new recordings
3. Analysis results will be stored in the `analyzed/` directory
4. Processed files will be stored in the `processed/` directory

## Supported Formats

- MP4 (video)
- WebM (video)
- WAV (audio)
- MP3 (audio)

## Analysis Features

- Emotion detection
- Semantic context analysis
- Speaker identification
- Sentiment analysis
- Meeting summary generation
